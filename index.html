QUIÉNES SOMOS

Un servicio pensado para facilitar tus compras

Ventas Temu es un emprendimiento creado para facilitar la compra de productos disponibles en línea. El sistema organiza la información de productos, clientes, proveedores y facturación, ofreciendo una interfaz clara y adaptable a diferentes dispositivos. La propuesta busca brindar una experiencia sencilla para registrar pedidos y administrar la información del negocio. El proyecto integra HTML5, CSS3, Bootstrap, JavaScript y posteriormente Flask, Jinja2 y PostgreSQL para gestionar los datos de manera estructurada. La aplicación también incorpora formularios, validaciones, autenticación de usuarios y operaciones de creación, consulta, actualización y eliminación de registros.
